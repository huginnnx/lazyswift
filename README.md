# lazyswift

Base de proyecto **Node.js + TypeScript** usando **pnpm** para una app **TUI** con [Ink](https://github.com/vadimdemedes/ink).

## Scripts

- `pnpm dev`: corre la TUI en modo dev
- `pnpm build`: genera `dist/`
- `pnpm start`: ejecuta el build
- `pnpm typecheck`: chequeo de tipos
- `pnpm lint`: eslint
- `pnpm format`: prettier

## Uso

```bash
pnpm install
pnpm dev
```

Salir: `q` o `Esc`.
